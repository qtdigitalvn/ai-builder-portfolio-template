# AI Builder Portfolio Template

Template lưu trữ 7 sản phẩm trong **7-Day AI Builder Challenge**.

Bạn không cần hoàn thiện portfolio ngay từ đầu. Sau mỗi ngày, hãy lưu lại bằng chứng tốt nhất để có thể trình bày hành trình xây sản phẩm AI của mình.

## Cách tải template

1. Bấm nút **Code** trên GitHub.
2. Chọn **Download ZIP**.
3. Giải nén file vừa tải.
4. Đổi tên thư mục thành:

```text
AI Builder Portfolio - [Tên của bạn]
```

Nếu bạn sử dụng GitHub, bạn cũng có thể bấm **Use this template** để tạo repository portfolio riêng.

## Cấu trúc portfolio

```text
01-workflow-newsletter/
02-mcp-website-data/
03-ai-skill/
04-deployed-automation/
05-landing-page/
06-scheduled-task/
07-executive-assistant/
PORTFOLIO-ENTRY-TEMPLATE.md
SECURITY-CHECKLIST.md
```

## Việc cần làm sau mỗi ngày

1. Mở thư mục tương ứng với ngày vừa hoàn thành.
2. Đọc file `README.md` trong thư mục đó.
3. Lưu ảnh chụp màn hình, video hoặc link demo.
4. Dùng `PORTFOLIO-ENTRY-TEMPLATE.md` để viết phần giới thiệu ngắn.
5. Lưu link bài checkpoint đã đăng trong cộng đồng.
6. Kiểm tra `SECURITY-CHECKLIST.md` trước khi chia sẻ công khai.

## Lưu ý

- Không đưa API key, mật khẩu hoặc token truy cập vào repository.
- Không tải file `.env` lên GitHub.
- Không chia sẻ dữ liệu cá nhân hoặc dữ liệu khách hàng.
- Nếu repository public, hãy kiểm tra lại toàn bộ file trước khi chia sẻ link.
